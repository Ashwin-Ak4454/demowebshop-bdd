# Demo Web Shop BDD Automation

This project is a test automation framework for [Demo Web Shop](https://demowebshop.tricentis.com/) using Selenium WebDriver, Java, Cucumber (BDD), and TestNG.

## Tech Stack

- Java 21
- Selenium WebDriver
- Cucumber BDD
- TestNG
- Maven
- WebDriverManager
- Page Object Model (POM)

## Project Structure
src ├── main │ └── java │ └── pages # Page Object classes ├── test │ ├── java │ │ └── stepdefinitions # Step definitions for Cucumber │ └── resources │ └── features # .feature files for test scenarios
